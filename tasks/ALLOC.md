User Story
----------

Я как Бизнес-заказчик, хочу одним нажатием подтвердить использование за квартал по своим моделям, чтобы сократить время подтверждения моделей в СУРМ.

Техническое описание
--------------------

Бизнес-заказчик (business_customer) должен иметь возможность перейти на страницу подтверждения использования модели по кварталу через кнопку "Подтвердить аллокацию за квартал" в СУРМ.

На странице подтверждения использования модели должен заполняться только активный квартал. Активный квартал - это квартал, доступный для заполнения.

Если в текущий момент активно два квартала, то система отображает только квартал, у которого осталось меньше дней до истечения возможности заполнить данные. Например, если Бизнес-заказчику доступно для заполнения и 1, и 2 квартал, то на странице продления отображается только 1 квартал.

  

Пользователю в форме подтверждения использования модели должен отображаться список моделей согласно следующей фильтрации:

*   Значение поля «Подразделение Владельца Модели/Алгоритма» должно совпадать с подразделением Бизнес-заказчика
    

*   В списке должны отсутствовать модели со статусом "Архив" и со статусом "Ошибка заведения"
  

На странице подтверждения использования модели должен быть текстовый поиск.

На странице подтверждения использования модели должна быть доступна фильтрация по значения атрибутов.

На странице подтверждения использования модели должны отображаться следующие поля:

1.  Идентификатор версии модели. Недоступно для редактирования. artefact_tech_label=system_model_id
    

2. Алиас модели. Недоступно для редактирования. Атрибут динамически собирается по следующим атрибутам: model + 'root_model_id'+v+'model_version'

3. Название модели. Недоступно для редактирования. artefact_tech_label=model_name_validation

4. Название модели в реестре ДАДМ. Недоступно для редактирования. artefact_tech_label=model_name

5. Владелец Модели/Алгоритма. Недоступно для редактирования. artefact_tech_label=business_customer

6. Дата подтверждения использования модели. Доступно для редактирования. Выбор даты ограничен: \[начала квартала; конец квартала + 1 месяц\]

По умолчанию атрибут заполняется текущей датой. Сохраненные данные должны отображаться в СУРМ в следующих атрибутах в зависимости от квартала usage_confirm_date_q1, usage_confirm_date_q2, usage_confirm_date_q3, usage_confirm_date_q4 (Artefact_tech_label)

7. Модель используется заказчиком. Доступно для редактирования. Сохраненные данные должны отображаться в СУРМ в следующих атрибутах в зависимости от квартала usage_confirm_flag_q1, usage_confirm_flag_q2, usage_confirm_flag_q3, usage_confirm_flag_q4 (Artefact_tech_label)

Если у модели есть значения из таблицы использования модели из ПИМ, то в текущем квартале предзаполняется значением из таблицы использования модели из ПИМ. Таблицу с данными по использованию модели из ПИМ необходимо реализовать.

Если у модели нет значения из таблицы использования модели из ПИМ и есть значения из предыдущего квартала, то в текущем квартале предзаполняется значением из предыдущего квартала

Если у модели нет значения из предыдущего квартала и нет значения из таблицы использования модели из ПИМ, то в текущем квартале значение пустое.

Пользовать должен иметь возможность просмотреть информацию об источнике предзаполнения текущего квартала: ПИМ, предыдущий квартал или "Нет данных"


На странице подтверждения использования должны быть доступны следующие действия:

*   "Сохранить". При выборе данной кнопки система должна записать непустые значение для заполняемого квартала в БД, выйти из режима продления использования модели и перейти в шаблон по умолчанию СУРМ.
    

*   "Отменить". При выборе данной кнопки система должна выйти из режима продления использования модели и перейти в шаблон по умолчанию СУРМ.
    

Значения полей "Дата подтверждения использования модели" и "Модель используется заказчиком" для моделей, созданных в СУМ, должны синхронизироваться из СУРМ в СУМ.

История изменения атрибутов должна отображаться в СУМ. - это проверить например изменнная дата не имела историчности по эндпоинту пусто - sum-rm-api/models/artefact/history?model_id=3b9a5408-7e6d-11f0-a1cd-36ce01504cbd&artefact_tech_label=usage_confirm_date_q1&model_source=sum
