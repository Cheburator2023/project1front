### Изменения в таблице (AdmiralDS/react-ui)

В реализацию таблицы были внесены следующие изменения:

1. **Изменения для оптимизации рендера колонок**
   - функции `renderRegularRow` и `renderRow` принимают параметр `columns: Column[]`.

**Компонент `VirtualBody` использует `columnList` для оптимизации отображения столбцов в таблице. Логика работы следующая:**

- stickyColumns - список sticky колонок
- visibleColumns - список колонок с оффсетом(visibleColumnCount), объединенный с stickyColumns
- Компонент отслеживает текущие позиции скролла (`scrollTop` и `scrollLeft`).
- Определяет видимые строки и столбцы на основе текущей позиции скролла и размеров области.
- Использует `useMemo` для оптимизации вычислений видимых строк и столбцов, предотвращая лишние рендеры.
- Отображает только те строки и столбцы, которые попадают в видимую область, с учетом предзагрузки, задавая отступы (`Spacer`) для корректного позиционирования.

2. **Колбек `onColumnDragEnd`:**
   - Новый колбек, который срабатывает после завершения перетаскивания столбца таблицы на новое место.

**Хранение информации о перетаскивании:**

- Введена переменная `dragInfo`, использующая `React.useRef`, для хранения информации о перетаскивании столбцов.
- Пример:
  ```jsx
  const dragInfo = React.useRef<{ columnName: string; nextColumnName: string | null } | null>(null);
  ```

**Обработка завершения перетаскивания (`handleDragEnd`):**

- В функцию `handleDragEnd` добавлена проверка и вызов колбека `onColumnDragEnd` с использованием данных из `dragInfo`.
